# Analises supervisionadas - Árvores de Decisão + Cross Validation

## Exercicio

Escolha uma base de dados em que haja um rótulo - deve servir para um modelo de classificação. (Exemplo: churn, aprovado/reprovado, bom pagador/mau pagador etc).

Escolha um dos algoritmos: Regressão Logística ou árvore de decisão (você pode usar os scripts compartilhados como base para o exercício). 

Rode o modelo e faça a avaliação dos resultados. 

Entregue um documento PDF explicando a base de dados, o desenvolvimento do modelo e as avaliações. 

Obs.: Trabalho pode ser realizado em duplas.
